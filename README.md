# Overview
In this work, we propose and validate:
1. Small models, through self-generated data, can achieve performance improvements that match or even exceed those obtained from distillation data generated by large models.
2. The data generated by SRA-MCTS is more diverse compared to data generated by CoT methods. Experimental results show that SRA-MCTS outperforms CoT in terms of model performance enhancement.

# Experimental Results
Through extensive experiments, we found:

1. **SRA-MCTS enhances the self-reasoning ability of small models**
   - Compared to data synthesized by the 70B model, SRA-MCTS achieves an average improvement of 2 points on Human-Eval and Human-Eval+ metrics at the 2B and 8B scales. Only at the 14B scale does the 70B synthesized data surpass SRA-MCTS.
   - SRA-MCTS-generated data leads to greater performance improvements in smaller models than distilled data from a 70B model.

2. **SRA-MCTS surpasses CoT in average performance**
   - SRA-MCTS outperforms CoT in almost all metrics except for MBPP+, and is only about 2 points behind Instruct on Human-Eval+.
   - When calculating the incremental average values for each model across different benchmarks, SRA-MCTS shows performance improvement at all scales, with a 5-point increase at the 8B scale and a 3-point increase at the 14B scale.

3. **SRA-MCTS excels in diversity, particularly in pass@10 metrics**
   - SRA-MCTS significantly outperforms CoT, especially in tasks requiring multiple generations, and shows stronger diversity, particularly in smaller models.

4. **SRA-MCTS shows both diversity and reliability as model size increases**
   - On smaller models, due to limited intermediate evaluation capability, SRA-MCTS mainly enhances diversity, with improvements observed primarily in the pass@10 metric (multiple generations).
   - As the model size increases, with better instruction-following and evaluation capabilities, SRA-MCTS not only performs well in pass@10, but also surpasses CoT in pass@1, showcasing the dual advantage of both diversity and reliability.

# Language Models and Datasets
We conducted experiments on gemma-2-2b, Meta-Llama-3.1-8B, and Qwen2.5-14B, using code domain evaluation datasets: human-eval, human-eval+, MBPP, and MBPP+.
